SYSTEM SETUP FOR THE LINUX LAB MACHINES

ENABLE THE HASKELL MODULE

  • In a terminal, run this code: echo 'module load haskell' >> ~/.bashrc
  • Your '.bashrc' file is where you add the commands you want to be run every time you create a new terminal. In this case, we are adding 'module load haskell', which does what it says on the tin: loads the Haskell module.
  • Any terminal or VSCode windows which are already open will need to be closed and reopened for the changes to take effect.

CONFIGURE THE VSCODE EDITOR

  • Open a VSCode window and DO NOT SIGN IN if prompted. Close the prompt by clicking the 'X' in the top right corner of the prompt instead. If another 'Sign in to use GitHub Copilot' prompt pops up, close that as well. DO NOT SIGN IN.
  • Press Ctrl + ',' or click "File -> Preferences -> Settings" to open the Settings menu. Search for 'chat.disableAIFeatures' and click the 'Disable AI Features' checkbox.
  • We also recommend disabling telemetry (i.e. automatically sending Microsoft your usage data). To do this, open the Settings menu and search "telemetry.telemetryLevel", then set the dropdown menu to 'off'. You may need to restart VSCode after changing this setting.
  • The "Haskell" extension should already be installed, but if it's not, you can install it by pressing Ctrl + P and entering "ext install haskell.haskell". If asked 'Do you trust the publisher "Haskell"?' select 'Trust Publisher & Install'.
  • Test HLS is working by creating a new Haskell file named "test.hs" (e.g. with "File -> New File" and naming it "test.hs"). This might give you a prompt saying "How do you want the extension to manage/discover HLS and the relevant toolchain?". Select "via PATH".
  • If it says "Need to download stack, continue?", click "No".
  • In "test.hs", start typing some invalid Haskell code, e.g. x = True && 'c'. If HLS is working, you should see that VSCode underlines the error. You might need to give it a little bit of time to load.

SET UP SEARCH ENGINES

Chrome / Chromium

  • "..." -> Settings -> Search engine -> Manage search engines and site search
  • To the right of "Site search", click "Add" and add each of the following:
    • DuckDuckGo (Private searches and no AI results)
      • Name: NoAI DuckDuckGo
      • Shortcut: noai.duckduckgo.com
      • URL with %s in place of query: https://noai.duckduckgo.com/?q=%s
      • Suggestions URL with %s in place of query: https://noai.duckduckgo.com/ac/?q=%s&type=list
    • Hoogle (Haskell API search engine)
      • Name: Hoogle
      • Shortcut: h
      • URL with %s in place of query: https://hoogle.haskell.org/?hoogle=%s
      • Leave 'Suggestions URL with %s in place of query' blank
  • To the right of "NoAI DuckDuckGo", click '"..." -> Make default' to make it your default search engine
  • Now, normal searches will go through DuckDuckGo and typing 'h' + Space will search Hoogle.

Firefox

  • Burger menu/"|||" -> Settings -> Search -> Additional search engines -> Add search engine
  • Add each of the following:
    • DuckDuckGo (Private searches and no AI results)
      • Search engine name: NoAI DuckDuckGo
      • URL with %s in place of search term: https://noai.duckduckgo.com/?q=%s
      • (Click Advanced) Suggestions URL with %s in place of search term: https://noai.duckduckgo.com/ac/?q=%s&type=list
    • Hoogle (Haskell API search engine)
      • Search engine name: Hoogle
      • URL with %s in place of search term: https://hoogle.haskell.org/?hoogle=%s
      • Keyword: h
  • Under "Default search engine" select "NoAI DuckDuckGo"
  • Now, normal searches will go through DuckDuckGo and typing 'h' + Space will search Hoogle.
