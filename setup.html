GETTING YOUR PC READY

TASK: The first thing to do when you start programming is to set up your computer. This page will help you to set up your environment for both imperative and functional programming. You will need to work within a Linux-enabled GUI environment, which has the clang compiler, the SDL2.0 libraries, the Haskell environment, and a text editor correctly installed. We provide tutorials for Windows 10 or 11, Linux Ubuntu, and macOS. We strongly recommend the use of the VS Code Editor as your main file editor, however, any editor of your choice will suffice if you do not need our support.

We provide you with two different 'Options' to setup your system. Option 1 is to use a personal laptop. You will need internet access and administrator permissions on your computer. Option 2 is to use the lab machines.

We recommend having a personal laptop for your degree. As a Computer Scientist, it's important to have control over your own machine and to understand how to administer it. It does not need to be a powerful or expensive laptop. In fact, a cheap laptop running Ubuntu is more suitable for this course than a £2000+ Macbook. If you have an old Windows laptop you don't use anymore, maybe because it got too slow, you may find installing Ubuntu on it gives it a new lease of life. If you don't have one, you can buy one second-hand or refurbished for relatively cheap. RAM will make the biggest difference in your user experience, so aim for 16GB or more. Jess' laptop was released in 2019 with 16GB of RAM and an Intel Core i5-8265U. Comparable laptops are available for ~£250 refurbished and ~£100 used on eBay (though be aware you may have to buy a charger separately). We can't help you with installing Ubuntu, but there are lots of tutorials out there on YouTube, e.g. this one.

If you are a 1st year undergraduate student then note that, in addition to the installations below, you will need Microsoft Teams installed on your system too. For your programming unit you will need to be able to access the Blackboard Website using your University of Bristol login details, that is your username and password.


OPTION 1 - Install Software Directly on Your Personal Laptop (recommended)

Windows: If you work with Windows 10 or 11 (64bit Home or 64bit Professional) then go through the steps in System Setup for Windows 10 or 11.

Linux: If you work with Ubuntu Linux then follow the installation instructions at System Setup for Ubuntu Linux.

 OSX: If you work with Apple/Mac/OSX then follow the installation instructions at System Setup for Mac OSX.

OPTION 2 - Using the Linux Lab Machines

If you're working on a lab machine, it's mostly set up already, but you should follow the System Setup for the Linux Lab Machines.
